Hva er Codex?

Codex er en spesialisert AI-modell fra OpenAI som er trent til å forstå og generere kode. Der ChatGPT hjelper med tekst og språk, er Codex eksperten som støtter deg i alt som handler om programmering.

Hva kan Codex gjøre?

  • 🔍 Finne og rette bugs i HTML, CSS og JavaScript
  • 🧠 Forklare hvordan kode fungerer
  • 🏗️ Lage komplette funksjoner eller moduler
  • ⚙️ Bygge API-integrasjoner og automatiseringer

Eksempler på bruk

Eksempel 1: En enkel knapp med teller i JavaScript

Prompt til Codex: Lag en knapp i HTML og JavaScript som øker en teller hver gang man klikker på den

Denne koden viser hvordan du kan lage en knapp som øker en teller hver gang du klikker på den. Et typisk eksempel der Codex kan hjelpe deg raskt i gang med interaktiv JavaScript.

<button id="btn">Klikk meg</button>
<p id="output">Klikk: 0</p>
let count = 0;
document.getElementById("btn").addEventListener("click", () => {
  count++;
  document.getElementById("output").textContent = "Klikk: " + count;
});

Eksempel 2: Kalkulere moms i Python

Prompt til Codex: Lag en Python-funksjon som regner ut pris inkludert moms

Her ser du hvordan Codex kan hjelpe deg med en nyttig funksjon for å beregne moms. Du kan enkelt angi beløp og momssats, og få riktig resultat tilbake.

def legg_til_moms(beløp, sats=25):
    return beløp * (1 + sats / 100)

# Brukseksempel:
print(legg_til_moms(100))  # Gir 125.0

Hvordan brukes Codex?

Når du bruker ChatGPT og skriver kode, aktiveres Codex automatisk i bakgrunnen – du trenger ikke å gjøre noe selv. Bruker du GitHub Copilot i Visual Studio Code, er det Codex som gir deg kodeforslagene i sanntid.

🧰 Slik kan du bruke Codex i egne prosjekter

Codex er ikke bare et verktøy for eksperter – det er en personlig kodepartner for alle som ønsker å bygge, lære eller forstå teknologi bedre.

  • Studenter: Få hjelp til å forstå kode og løse oppgaver raskere
  • Utviklere: Bygg moduler, refaktorer eller generer boilerplate-kode på sekunder
  • Gründere: Lag fungerende prototyper uten å være utvikler
  • Lærere: Lag små, forklarende kodeeksempler til undervisning

Du kan bruke Codex i ChatGPT ved å formulere enkle spørsmål som:

  • "Hva gjør denne koden egentlig?"
  • "Lag et kontakt­skjema i HTML og JS"
  • "Finn feilen i denne CSS-koden"
  • "Hvordan sender jeg en POST-request i JavaScript?"
